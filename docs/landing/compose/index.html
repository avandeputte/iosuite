Build your Docker stack

Pick the apps and answer a few questions. You get one docker-compose.yml with nothing left to edit: start it, and the suite is running with its databases, your admin account and the addresses you chose.

The file is written in your browser. Nothing you type here is sent anywhere, and nothing is kept when you close the page.

1 The apps

Each app runs in its own container. Add or remove one later by opening your file here again.

2 The database

The Shared ioSuite database holds the accounts and the suite's settings. If ioThing apps elsewhere already use one, enter its name, user and password here and this stack shares their accounts.

3 The first admin

A suite admin: an admin of every app, and the one who adds the family's accounts.
