one app or all of them

You don't need the whole suite.

There is no suite to install first and no central server to run. Each app is the whole product for what it does; the others only add to it.

just one

A photo app, and nothing else? Fine.

Install ioPix with one command. It needs a MariaDB or MySQL server for its data and its accounts, and that's it: no start page, no other apps, nothing waiting for something you didn't install.

add one later

Grow when you want to

Months later, install ioCalendar and point it at the same account database. Everyone already has an account, and with a shared domain one sign-in covers both. Nothing about the first app changes.

or all at once

The whole suite in one go

Every installer ends with "Also install…?". Tick the others and they go in the same machine or container, each with its own database and port, without asking the shared questions twice. Or run the whole-suite Docker stack.

ioContacts + ioCalendar: a Birthdays calendar from your contacts, and the people on an event picked from them.
ioPix + ioContacts: the face named in ioPix becomes the contact's photo, on every phone.
ioSuite + any app: a tile with what matters today: the next events, photos from this day, last night's sleep.
Any two apps: the same accounts, roles per app, one sign-in, one admin panel, the same Settings in every app.

install

Pick your apps. One is enough.

Tick what you want and copy the command. Each app's installer asks for its database, the shared account database and an admin, then starts the service. The requirements are short.

proxmox ve host, as root — ioPix
$ bash -c "$(curl -fsSL https://raw.githubusercontent.com/avandeputte/iopix/main/proxmox/ct/iopix.sh)"

then Open http://<host>:<port> and sign in

ioPix 8600ioNotes 8610ioCalendar 8620ioSuite 8630ioContacts 8640ioHealth 8650

Every app has its own default port, so all of them fit on one host. The installer creates the admin you answered; with several apps it is the same admin everywhere, because the accounts live in one Shared ioSuite database.

Then put the apps behind your reverse proxy for HTTPS (Caddy, nginx, HAProxy or a Cloudflare Tunnel), and every app updates itself from Settings › Server.
