ioSuite Bookmarks

Keeps this browser's bookmarks the same as your start page's, both ways: the bookmarks bar, the other bookmarks and, in Firefox, the bookmarks menu. What you add, change or delete here goes to the start page and to your other browsers, and the other way round.

The first time

How it lines up

  • The bookmarks bar is the folder Bookmarks bar on the start page, in every browser.
  • Firefox's bookmarks menu is the folder Bookmarks menu; Chrome and Edge show it as a folder in Other bookmarks.
  • Other bookmarks is everything else at the top of the start page's bookmarks.
  • Vivaldi keeps one tree: the folder set as its bookmark bar is Bookmarks bar, and everything else in Bookmarks (Speed Dial folders too) is what other browsers show as Other bookmarks. What goes to Vivaldi's Trash is deleted on the start page.

It syncs a few seconds after a bookmark changes here, and asks the start page every minute whether anything changed there. It signs in with an app password of its own, for sync only: listed, and removable, under Settings › Account on the start page.
